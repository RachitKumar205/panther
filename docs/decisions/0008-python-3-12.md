# 0008 — Target Python 3.12

- **Status:** accepted
- **Date:** 2026-11-20
- **Phase:** M0

## Context

The server image installs `python3.12` from the CUDA UBI9 base, and the old project required
`>=3.11`. The local machine has 3.14, but the deployment target is the server image.

## Decision

Target Python **3.12**: `requires-python = ">=3.12,<3.13"` in the workspace, with an explicit
`.python-version` pin for uv.

## Alternatives considered

- **3.13 / 3.14.** Rejected until torch/transformers wheels in the CUDA image are verified.
- **3.11.** Rejected: no benefit, and the server has 3.12.

## Consequences

Modern typing (`type` aliases, `Self`, `override`) is available; CI must use 3.12.
